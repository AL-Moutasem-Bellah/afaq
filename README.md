# منصة آفاق — نسخة الاختبار المحلية

هذه نسخة full-stack محلية: الواجهة الأمامية في `index.html` و`app.js`، والخادم وقاعدة البيانات في `server.py` و`afaq.db`.

## التشغيل في VS Code

1. افتحي مجلد `afaq-school` في VS Code.
2. افتحي Terminal داخل المجلد.
3. شغّلي:

   ```bash
   python3 server.py
   ```

4. افتحي في المتصفح: `http://localhost:8000`

> لا تفتحي `index.html` مباشرة أو عبر Live Server، لأن الموقع يحتاج أن يعمل من خادم Python كي يتصل بقاعدة البيانات ويرفع الملفات.

## التجربة

1. أنشئي حساب طالبة وأضيفي دليلًا مع نص وصورة أو فيديو (حتى 100 MB).
2. أنشئي حساب نائب مدير في نافذة خاصة أو سجّلي الخروج.
3. افتحي «المراجعة والتقييم»: سيظهر النص الكامل والدليل، ويمكن فتحه وتقييمه من 0 إلى 5.

## التخزين

- قاعدة البيانات المحلية: `afaq.db`
- الصور والفيديوهات: مجلد `uploads`

هذه الملفات محلية للتجربة فقط. في النسخة النهائية ستنتقل إلى قاعدة بيانات وتخزين سحابي وربط نطاق وإرسال بريد فعلي.
